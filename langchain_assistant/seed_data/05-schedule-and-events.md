# Schedule and Live Events

This schedule applies to Northstar cycles running from July through September 2026. All listed times use Coordinated Universal Time (UTC).

## Recurring events

- **Live question session:** Wednesday at 18:00 UTC.
- **Weekly review room:** Friday at 16:00 UTC.
- **New-cycle orientation:** First Monday of each month at 17:00 UTC.
- **Optional planning clinic:** Second Tuesday of each month at 19:00 UTC.

Live events are optional. Recordings and written summaries are normally published within 24 hours.

## Cycle dates

The scheduled cycle start dates for this period are:

- July 6, 2026
- August 3, 2026
- September 7, 2026

The September cycle starts on September 7 rather than the calendar month's first Monday because the program observes a maintenance closure on August 31.

## Time-zone handling

The assistant should preserve the source time in UTC and may additionally convert it to the learner's stated time zone. It should label both values clearly. It must not guess the learner's time zone from an IP address, language, or previous travel discussion.

## Event changes

Temporary changes are announced in a dated schedule notice. When a notice conflicts with this document, the newer current official notice takes precedence for the affected date only.

## Missed events

Missing a live event does not block progress. The learner should use the recording or written summary and create a follow-up task only if the missed event covered a current learning objective.

## Calendar reminders

Creating an external calendar event would be a write action and requires the learner's approval. Merely describing the schedule or suggesting a reminder is read-only and does not require approval.
